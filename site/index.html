Features

Say it instead of typing it.

fishpr sits in your system tray and stays out of the way. There's no window to switch to and nothing to set up.

Hold to talk

Hold Ctrl+Space in any app. A small "Recording…" pill shows you're live. Let go, and the text arrives about half a second later.

Pastes it for you

The text is put on the clipboard and pasted into the focused window. If pasting fails, it's still on your clipboard, so nothing you said is lost.

Ignores silence

A voice check runs on your machine before anything is sent. Press the keys by accident and nothing happens. You won't get a made-up "Thank you." pasted in.

Or click the tray icon

Click once to start and again to stop. The tray icon and the shortcut share one state, so you can start with one and stop with the other.

Quiet when it works

You only get a notification when something goes wrong. Otherwise the only sign that fishpr is there is the text showing up.

Small and native

A single Rust binary of about 14 MB, installed from a signed package repo. Updates arrive with your normal pacman -Syu or apt upgrade.

How it works

From your voice to your cursor in four steps.

When you let go of the keys, fishpr checks the recording for speech and, if you said something, sends it off for transcription.

Record

While you hold the keys, your mic is recorded through PipeWire with pw-record.

Check for speech

Silero VAD, a small voice-activity model, listens for a voice. If there's only silence, the recording is thrown away.

Transcribe

The audio is uploaded to ChatGPT's dictation service, the one behind the microphone button on chatgpt.com.

Paste

The text goes on your clipboard, and fishpr presses Ctrl+V in the focused window.

Before you install: the transcription service is unofficial and undocumented, so OpenAI can change or block it at any time. Your audio is sent to OpenAI, so don't dictate anything you wouldn't type into ChatGPT. fishpr isn't affiliated with OpenAI.

Install

One command, and it's running.

The installer adds fishpr's signed package repo, installs fishpr, sets it to start on login, and starts it.

Konsole
# Install and start fishpr
$ curl -fsSL https://raw.githubusercontent.com/srafis/fishpr/main/install.sh | sh

# Then, in any app:
#   hold Ctrl+Space, speak, let go

# Control it from a script or another key binding
$ fishpr --toggle

# Quit
$ pkill -x fishpr

FAQ

Questions

Does it cost anything, or need an account?

No. fishpr is free and MIT-licensed, and it doesn't need an OpenAI account or API key.

Where does my audio go?

The speech check runs on your machine, so recordings with nobody speaking never leave it. If you did speak, the recording is uploaded to OpenAI for transcription, the same as using the microphone button on chatgpt.com while logged out. Don't dictate anything you wouldn't type into ChatGPT.

Will it keep working?

It depends on an unofficial service that OpenAI can change or block at any time. If that happens, you'll see "Transcription failed" and need to wait for a fix. The backend is isolated in one file, so moving fishpr to another service, such as OpenAI's official API, is a small change.

Does it work on GNOME?

No. fishpr is built for KDE Plasma 6 on Wayland. On other desktops you can try binding fishpr --toggle to a key, but there's no support for them.

Why do I need permission to paste?

KWin doesn't let apps fake key presses, so fishpr presses Ctrl+V on a virtual keyboard instead. The package installs a udev rule that lets it do that silently. Without the rule, fishpr asks for remote-control permission once and shows an indicator on every paste.

How do I update or uninstall it?

Updates come with your normal system upgrade. Restart fishpr afterwards, or run the install command again to update and restart it in one go. To uninstall, remove the package with sudo pacman -R fishpr-bin or sudo apt purge fishpr, then remove the repo. The README lists each step.
